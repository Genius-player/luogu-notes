# P5718 找最小值
**题目类型：数组/模拟，基础循环**

## 题目简述
给定数字个数n，再输入n个非负整数，输出这n个整数里面的最小值。

## 用到知识点
1. C++ vector动态数组，运行时根据n确定数组长度，使用`[]`访问元素，牢记vector定义数组用()
2. `sort()`排序函数，搭配头文件`<algorithm>`，默认从小到大升序排列
3. 循环读取多组输入数据

## ⚠️ 容易踩坑的地方
1. 初始最小值不要随便设成0，如果所有数字都大于0不会出错；但规范做法是直接拿第一个输入数字作为初始最小值。
2. vector创建大小时使用圆括号`vector<int> a(n)`，访问元素用方括号`a[i]`，两种括号不要弄混。
3. 读取n之后，要完整读取后面n个数字，不要漏读。

## 解题思路
1.用vector生成动态数组
2.sort（）给数组排序
3.取最大值用a[n-1],最小值用a[0]

方法二（vector+sort排序）：
> 使用vector创建长度为n的动态数组，循环读取所有数字存入数组。调用sort从小到大排序，排序完成后数组第一个元素就是最小值。
## 总结
这道题有两种可行写法。第一种只用变量边读边比较，不需要存储全部数据，节省内存，效率更高；
第二种借助vector动态数组配合sort排序，代码直观好写，适合后续需要保留全部数字的场景。要牢记vector语法区分：尖括号`<int>`规定存储类型，创建容器容量用圆括号`(n)`，访问元素使用方括号`[i]`。
