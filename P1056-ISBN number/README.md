# P1056 ISBN号码
**题目类型：字符串处理、模拟**

## 题目简述
判断ISBN识别码是否正确。
规则：提取前9位数字，第i位 × i，求和后对11取余；余数10用大写X，其余为数字。
如果校验码和输入末尾一致输出Right，否则输出正确ISBN。

## 用到知识点
1. C++ string字符串，`string.size()` 获取长度
2. `substr()` 字符串截取操作
3. 字符转数字：`char - '0'`；数字转回字符：`num + '0'`
4. 循环遍历字符串，`continue`跳过分隔符`-`
5. size_t与int类型对比警告（有符号、无符号整数区别）

## ⚠️ 容易踩坑的地方
1. 加权相乘：第1位×1，第2位×2，不能直接乘计数器`a`，要写成`a+1`（本题最致命逻辑错误）
2. 余数等于10时，校验码必须是**大写X**，小写x会判定错误
3. `isbn.size()`返回`size_t`无符号类型，和int变量比较会触发警告（警告不影响答案，属于类型规范问题）
4. 只取前9个数字参与计算，分隔符`-`要跳过，不能当成数字处理

## 解题思路
1. 读取完整ISBN字符串
2. 遍历字符串，跳过`-`，收集前9位数字
3. 按规则加权累加求和，对11取模算出正确校验码
4. 和输入末尾识别码对比：相同输出Right；不同则替换末尾字符输出正确ISBN

## 总结
字符串模拟题，核心在于**区分字符和数值**，小心加权的下标偏移陷阱。
substr适合快速截取前缀，但只能操作字符串，不能对int数组使用。
