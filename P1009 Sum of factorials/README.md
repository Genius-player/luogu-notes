# 题号 P1009 [NOIP1998 普及组] 阶乘之和
**题目类型：** 高精度，数组模拟大整数

## 题目简述
输入正整数n，计算 $S = 1! + 2! + 3! + \dots + n!$。$1\le n\le50$。
由于结果数值极大，普通整型存不下，需要高精度大整数计算。

## 用到知识点
1. 高精度大整数：用数组存储数字每一位，模拟竖式乘法、竖式加法。
2. 阶乘递推：$k!=(k-1)! \times k$，不用每次从头计算阶乘，减少运算量。
3. 数组处理进位，逆序存储数字（低位放在数组下标0，方便进位）。

## ⚠️ 容易踩坑的地方
1. int / long long 范围有限，n超过20就溢出，不能直接用普通变量存阶乘。
2. 数组存储大整数，一般逆序存放（个位放a[0]），进位处理更简单。
3. 每次乘法、加法后，要清理前导0，输出时不要输出多余的0。
4. 阶乘递推，必须保留上一轮阶乘的数组，不要每次重新计算。
5. 数组大小要开足够大，50!最多65位，数组开100足够。

## 解题思路
1.创建高精度数组
2.写高精度乘法函数
3.写高精度加法函数
4.逆序读书，跳过前导0，定位最高有效数字
5.逆序输出结果
## 总结
本题的难点在于50!数值远超普通整型的存储上限，必须用高精度数组模拟竖式运算。
利用阶乘递推公式 $k!=(k-1)! \times k$，不用重复计算，优化计算效率。
高精度一般逆序存储数字，方便进位处理，计算完成后要跳过前导零再输出。
