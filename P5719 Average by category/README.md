# P5719 分类平均
**题目类型：循环、分支判断，浮点数计算**

## 题目简述
给定n和k，把1~n的正整数分成两类：A类能被k整除，B类不能被k整除。输出A、B两类各自的平均数，保留小数点后1位，空格隔开。题目保证两类都不为空。

## 用到知识点
1. 取模运算符`%`：`i%k==0`用来判断i是不是k的倍数。
2. 整数转浮点运算：`1.0 * sum / cnt`，用1.0强制转换成double，避免整数除法直接截断小数。
3. 输出格式控制：`fixed`与`setprecision(1)`，用来固定保留1位小数，需要`<iomanip>`头文件。

## ⚠️ 容易踩坑的地方
1. 输出不做格式限定，会出现小数位数不对（比如输出56而不是56.0），直接WA。
2. 忘记强制类型转换，直接`sum1/ans1`变成整数除法，小数部分丢失。
3. 不要漏掉头文件`<iomanip>`，否则setprecision无法生效。

## 解题思路
1.for循环遍历1-n的各个数
2.if-else嵌套将数分类成A，B两类数
3.sum和ans分别计算出数值之和和数值个数
4.强制转浮点求出平均数
## 总结
本题核心思路是遍历1到n的全部数字，利用取模运算区分两类数字，分别累加总和并统计数量。
计算平均值时，要利用`1.0`做强制类型转换，防止整数除法丢失小数；
输出时必须用`fixed`和`setprecision`控制输出格式，保证固定保留1位小数，否则即使数值正确也会因为格式问题无法通过评测。
