# 题号 P1980 [NOIP2013 普及组] 计数问题
**题目类型：** 枚举，数位统计

## 题目简述
给定整数 n 和数字 x，统计 1 ~ n 的所有整数里面，数字x一共出现多少次。
数据范围：$1\le n<10^6,\ 0\le x \le9$

## 用到知识点
1. 枚举循环：遍历1到n全部数字。
2. 数位拆分：对一个整数，用`%10`取出个位，`/10`去掉个位，循环拆分每一位。
3. 计数器累加：每找到一位等于x，计数器+1。

## ⚠️ 容易踩坑的地方
1. x是0的时候要小心，1~n不会有前导0，不能错误统计前导零。
2. 拆分数字的时候，临时变量不能直接修改循环变量i，要用temp拷贝i的值。
3. n最大是$10^6$，循环1e6次C++完全能跑，不会超时。
4. 注意：是**每一位**都统计，不是统计有多少个数包含x（例如11里面1要算2次）。

## 解题思路
1.用for循环枚举出从1到n的各个数
2.用temp对10取余判断是否有x出现，有则用cnt累加
3.用temp = temp / 10 去掉已判断的个位
## 总结
本题可以暴力枚举1~n所有数字，对每个数字逐位拆分，取出每一位判断是否等于目标数字x并计数。
因为n上限是1e6，暴力枚举时间足够，代码简单好写。
也可以用数位DP做（进阶），对于本题数据范围暴力就足够。
