# P1307 [NOIP2011 普及组] 数字反转
## 题目简述
给定整数 $N$，将该数各个位上数字反转得到一个新数。
新数不能带有前导零；原数为0时直接输出0。
数据范围：$-1,000,000,000 \le N \le 1,000,000,000$
输入：一个整数N
输出：反转后的整数

## 用到知识点
1. 整数数位拆分：`%10`取出个位数字，`/10`去掉个位，整数运算。
2. 长整型 long long：存储大数，防止数值溢出。
3. 分支判断：区分正数、0、负数三种情况处理。
4. 循环拼装数字：循环把取出的个位拼到新数字上。

## ⚠️ 容易踩坑的地方
1. int范围有限，存储接近1e9反转结果会溢出，要用long long。
2. 区分字符'0'和数字0，cout输出数字不能加单引号。
3. 不需要数组处理前导0，拼装数字的过程天然自动舍弃前导0。
4. 整数拆位要用整数10，不能用浮点数10.0，避免精度错误。
5. 负数要先取绝对值翻转，最后再补上负号。

## 解题思路
用数位拆拼法 会自动省略最高位0的反转值
三种情况分开计算
负数输入和输出值需特殊计算一次
## 总结
- 取模%10拿个位，整除/10删掉个位，循环完成数字翻转。
- 整数拼接的方式天然去掉反转后产生的前导0，不用额外处理。
- 大数一定要用long long，防止溢出。
- 分开正负分支处理逻辑更直观，注意负数最后输出负号。
