# P5724 求极差
## 题目简述
给定n和n个整数ai，极差定义为一组数字最大值减去最小值。
第一行输入正整数n，代表整数个数。
第二行输入n个整数，空格隔开。
输出这n个整数的极差。
数据范围：1 ≤ n ≤ 100，0 ≤ ai ≤ 1000

## 用到知识点
1. vector动态数组：可以用变量n指定容器大小，下标从0开始。
2. sort排序函数，需要引入头文件#include <algorithm>，默认从小到大升序排列。
3. vector迭代器：begin()获取起始迭代器，end()获取末尾后一位迭代器。
4. vector访问元素，支持a[下标]读取，和普通数组用法一致。

## ⚠️ 容易踩坑的地方
1. vector下标范围0~n-1，循环写成i=1;i<=n会数组越界。
2. 数组越界不会编译报错，但读到随机脏数据，答案出错，属于隐性bug。
3. 使用sort必须引入algorithm头文件，漏写直接编译失败。
4. end()不是最后一个元素，是末尾后一位，不能直接拿来取值。

## 解题思路
1.先用vector创建动态数组
2.for循环逐个输入整数 i必须从0开始递增
3.sort给数组排序
4.调用末尾减开头
## 总结
- vector下标从0开始，写循环要注意边界，避免数组越界。
- sort排序可以快速拿到最值，简化求极差的代码。
- sort函数必须携带algorithm头文件。
- 数组越界属于隐性bug，编译无错但答案错误。
