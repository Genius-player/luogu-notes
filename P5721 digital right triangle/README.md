# 题号 P5721 【深基4.例6】数字直角三角形
**题目类型：** 循环嵌套，格式化输出

## 题目简述
输入正整数n，输出直角边长为n的数字直角三角形。数字连续递增，每个数字占2位，不足两位前面补前导0。一共n行，第一行n个数，之后每行数字数量依次减1，最后一行1个数。

## 用到知识点
1. 双层for循环：外层控制行数，内层控制每行输出数字个数。
2. C++格式化输出：`setw()`、`setfill()`，头文件 `<iomanip>`。
    - `setw(2)`：设置单次输出宽度为2；
    - `setfill('0')`：空位使用字符0填充，参数必须是**单引号字符**。
3. 变量自增，连续计数。

## ⚠️ 容易踩坑的地方
1. setfill里面必须是单引号`'0'`，双引号`"0"`是字符串，编译报错。
2. 内外循环变量不能同名，比如外层i，内层不能再定义i，会变量覆盖逻辑错乱。
3. endl不能写在内层循环，否则输出一个数字就换行；要等一整行全部输出完再换行。
4. num自增只写一次，重复写num++会导致数字跳号。
5. 内层循环条件要写`j <= count`，不要写错循环更新表达式。

## 解题思路
1.观察好各行输出个数 用n-i+1表示
2.用外层for循环控制行数
3.内层for循环控制输出个数
4.输出用setw（）控制输出宽度，setfill（）操控填充
## 总结
本题核心是双层循环控制图形行数与每行数字数量。
格式化输出时setfill只接收char类型，单双引号是高频编译错误点。
需要注意换行位置，所有数字输出完毕后再换行，保证同一行数字拼接在一起。
循环变量命名要区分内外层，防止变量覆盖破坏循环逻辑。
