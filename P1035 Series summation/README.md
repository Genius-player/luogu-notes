# P1035 [NOIP2002 普及组] 级数求和
**题目类型：** 循环模拟

## 题目简述
已知调和级数 $S_n=1+\frac12+\frac13+\dots+\frac1n$。给定整数 $k$，求满足 $S_n>k$ 的最小正整数 $n$。
输入：一个正整数 $k$（$1 \le k \le 15$）
输出：最小的n

## 用到知识点
1. 浮点类型：`double` 存储累加的小数和，int不能保存小数。
2. 浮点数除法：`1.0 / i`，用1.0触发浮点运算；直接写`1/i`是整数除法，结果恒为0。
3. 无限for循环：`for(int i=1;;i++)`，省略第二个表达式代表循环条件永远成立，依靠`break`退出循环。
4. break语句：满足条件时跳出循环，终止迭代。

## ⚠️ 容易踩坑的地方
1. 累加和sum不能用int类型，小数丢失会造成死循环。
2. 必须写`1.0 / i`，不能写`1 / i`，整数除法会全部变成0，sum永远不变。
3. 注意顺序：先累加，再判断是否大于k，不能颠倒逻辑。
4. cnt计数要和i同步，每次累加一项cnt+1。

## 解题思路
1.无限for循环不断计算sum值 cnt记次数
2.if判断 sum大小满足自动跳出循环
## 总结
本题使用无限for循环逐项累加调和级数，每次累加后判断总和是否超过k，一旦满足条件就break跳出循环，输出当前计数cnt。k最大为15，循环次数可控，不会超时。
