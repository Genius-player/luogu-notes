# P2669 [NOIP2015普及组]金币
**题目类型：** 循环模拟

## 题目简述
国王给骑士发金币。第1阶段，连续1天，每天1枚金币；
第2阶段，连续2天，每天2枚金币；
第3阶段，连续3天，每天3枚金币；
第n阶段，连续n天，每天n枚金币。
给定总天数k，求前k天骑士一共拿到多少金币。
输入：正整数k
输出：总金币数量

## 用到知识点
1. while循环，循环条件控制全局总天数，逐天进行模拟。
2. 设置局部计数器cnt，记录当前阶段内已经经过的天数。
3. long long类型存储总和，防止累加结果超出int范围溢出。
4. 分段逻辑：当前阶段天数耗尽时切换到下一阶段，并重置阶段内计数器。

## ⚠️ 容易踩坑的地方
1. 分清两个计数器：day是全局总天数，cnt是当前阶段内部的天数，不能混淆。
2. 总和sum不能使用int，k较大时累加结果会溢出，必须用long long。
3. 阶段切换时机：当cnt等于n时，才代表本阶段走完，更新n并把cnt清零。
4. 循环终止条件是全局总day到达k，不能提前退出。

## 解题思路
1.while循环控制天数累加 直到k天
2.if判断 当当前阶段已走过n天 自动切换下一个阶段
## 总结
采用逐天模拟的思路，每一天都累加对应金币。
用day记录全局已经过的天数，cnt记录当前阶段的内部天数。
当当前阶段内部天数cnt达到n，就切换到下一个阶段。
循环直到统计满k天，输出金币总和。
