# P1420 最长连号
## 题目简述
输入长度为n的正整数序列，求序列中最长连号的长度。
连号定义：从小到大连续自然数组成的连续子串，后一个数比前一个大1。
第一行输入整数n。
第二行输入n个整数ai，空格隔开。
输出最长连号的长度。
数据范围：1 ≤ n ≤ 10000，1 ≤ ai ≤ 10^9

## 用到知识点
1. vector动态数组，用于存储读入的序列，下标从0开始。
2. 顺序遍历数组，一次循环完成查找，时间复杂度O(n)。
3. 双变量记录：current_len保存当前连续段长度，max_len保存全局最长长度。

## ⚠️ 容易踩坑的地方
1. 初始值设置，current_len和max_len都要初始化为1，单个数字长度就是1，不能初始为0。
2. 循环i从下标1开始，对比a[i]和a[i-1]，不要越界访问数组。
3. 连号断开时，current_len重置为1，不是重置为0。
4. 数据n最大10000，vector完全可以承载，不需要担心容量不足。
5. ai可以很大，用int就足够存储，不需要long long。

## 解题思路
1.用vector生成动态数组并存入整数
2.for循环按序将后整数减前一个整数
3.值为一则不断加一计数 超过历史最大长度就赋值给它 不唯一马上重置子串长度
## 总结
- 遍历数组，判断后一项减前一项是否等于1，以此判定连号。
- current_len在连续时自增，断连重置为1。
- max_len不断更新，记录遍历过程里遇到的最大连号长度。
- 只需一趟循环遍历，效率高，可以处理n到10000的数据。
