# P5723【深基4.例13】质数口袋
## 题目简述
从2开始依次判断自然数是否为质数，若是质数就放入口袋。口袋内所有数字之和不能超过给定的L。
需要从小到大依次输出装入口袋的所有质数，最后输出最多能装下的质数个数。
输入：一行一个正整数L
输出：每行输出一个质数，最后一行输出质数总数量

## 用到知识点
1. 自定义bool函数：封装质数判断逻辑，返回true/false。
2. 质数判定：检验2~√x区间内有无因数，若无则为质数，sqrt()需要引入<cmath>头文件。
3. while(true)无限循环：循环次数不确定，内部通过break退出循环。
4. 累加与计数：sum记录质数总和，cnt统计质数数量。

## ⚠️ 容易踩坑的地方
1. 判断超重时，要先检验 sum+num 是否超过L，超过就不能加入这个质数。
2. sqrt()返回小数，需要包含cmath头文件，否则编译报错。
3. 2是唯一偶质数，质数判断逻辑不能漏掉2。
4. 输出格式：每个质数单独占一行，最后才输出总数。
5. 小于2的数一定不是质数，质数函数开头要过滤。

## 解题思路
1.用bool函数判断是否为质数
2.用无限循环 break可跳出
3.if（Prime（））让质数才能进入计算过程
4.手动給num递增 否则答案全是2
5.记得一行输出一值 最后输出cnt
## 总结
- 不确定循环次数适合while(true)+break。
- 判断质数只需要枚举到根号x，减少循环次数。
- 先预判加上当前质数会不会超限，超限就停止。
- 自定义函数可以把判断质数的逻辑单独封装，代码更清晰。
