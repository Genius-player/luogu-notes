# P5720 一尺之棰
**题目类型：循环模拟**

## 题目简述
输入木棍初始长度a，每天将木棍长度砍掉一半，每次除以2并向下取整。求木棍长度第一次变为1时是第几天。

## 用到知识点
1. while循环：适合循环次数预先不确定的场景，条件成立就持续执行循环体。
2. long long长整型：用于存放较大数字，本题a最大可达1e9，防止int溢出。
3. C++整数除法：两个整数相除，自动向下取整。

## ⚠️ 容易踩坑的地方
1. 天数初始值极易出错，初始木棍本身是第1天，不能把day初始化为0，否则结果会少1。
2. 循环终止条件不能写错，条件写错会出现死循环或者答案偏差。
3. 数据上限1e9，用int会存在溢出风险，推荐用long long类型存储。

## 解题思路
while循环让a不断除2 同时day++
## 总结
本题使用while循环模拟木棍每日减半的过程。
要注意初始天数是1，不是0，这是本题最容易出错的关键点。
整数除法在C++里自动向下取整，刚好匹配题目要求。
处理大数时选用long long，规避整型溢出问题。
