# P1217 [USACO1.5]回文质数 Prime Palindromes
## 题目简述
找出区间$[a,b]$（$5 \le a < b \le 100000000$）中，同时满足是回文数、质数的所有数字。
回文数定义：从左往右读和从右往左读数字相同。
输入：一行两个正整数 a，b
输出：每一行输出一个符合条件的回文质数

## 用到知识点
1. 自定义bool函数：封装判断质数、判断回文的逻辑，返回true/false。
2. 质数判定：检验2~√x区间内有无因数，若无则为质数，`sqrt()`需要引入`<cmath>`头文件。
3. 回文数判定：循环取出数字个位，翻转数字，对比翻转后的数和原数。
4. continue语句：直接结束本轮循环，进入下一次循环。
5. 数学性质优化：除11以外，所有偶数位数的回文数一定不是质数，可以直接跳过。

## ⚠️ 容易踩坑的地方
1. 回文判断要用while循环，不能用if，if只会执行一次，无法完整翻转数字。
2. len代表数字的位数，`len%2==0`判断的是位数是否为偶数，不是判断数字本身是否为偶数。
3. 11是唯一的偶数位回文质数，写判断条件时要单独保留11，不能一起跳过。
4. 题目数据上限到1亿，如果不做位数优化，暴力枚举会超时。
5. 质数判断函数要过滤小于2的数字，小于2一定不是质数。

## 解题思路
1.bool函数用倒置法判断是否为回文数
2.bool函数判断是否为质数
3.getLen函数判断回文数位数
4.主函数先省去多余回文和质数，再判断是否满足两个条件
## 总结
- 回文判断核心思路：逐位取出个位，构造翻转后的数字，对比原值。
- 偶数位回文数（除11）一定能被11整除，不是质数，可以直接跳过。
- continue可以省去多余的回文、质数判断，减少运算量防止超时。
- 多个判断逻辑可以封装成独立函数，代码可读性更高。
